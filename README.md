# My Banner App 🚀

ഇതൊരു ലളിതമായ ആൻഡ്രോയിഡ് ആപ്ലിക്കേഷനാണ്. ഗൂഗിൾ ഡ്രൈവിൽ ഉള്ള ബാനറുകൾ ഈ ആപ്പിലൂടെ നേരിട്ട് കാണാനും, ലിങ്കുകൾ ആപ്പിനുള്ളിൽ തന്നെ തുറക്കാനും സാധിക്കും.

## പ്രധാന ഫയലുകൾ
* `MainActivity.java` - പ്രധാന ആൻഡ്രോയിഡ് കോഡ്.
* `AndroidManifest.xml` - ഇന്റർനെറ്റ് പെർമിഷൻ നൽകിയിട്ടുള്ള ഫയൽ.
* `index.html` - ഗൂഗിൾ ഡ്രൈവിൽ അപ്‌ലോഡ് ചെയ്യേണ്ട ബാനർ ഡിസൈൻ.
